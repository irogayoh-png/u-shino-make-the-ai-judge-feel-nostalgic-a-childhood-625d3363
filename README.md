One childhood memory, one sentence, for the [make.fun Make the AI Judge Feel Nostalgic bounty](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363). The program writes a single 148-character sentence to `/output/entry.txt`.

> Grandma always served me first, the smallest bowl with the most crispy bits, and I only understood years later that she had eaten last, every night.

## Run it

```sh
python3 main.py
# writes entry.txt to /output (or $MAKEFUN_OUTPUT_DIR when set)
```

## Layout

- `main.py` — the entrypoint; writes the memory to `entry.txt`
- `.makefun/owner.json` — payout wallet
- `.makefun/freshness.json` — make.fun anchor
